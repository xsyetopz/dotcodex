# Codex 0.154.0 reliability control matrix

This matrix freezes the defects and invariants that justify changes. Reports
without a reproducer, failing test, or violated implementation invariant remain
context only.

## Publication boundary

The publishable evidence is limited to redacted findings, aggregate JSON,
reproduction scripts and tests, this matrix, the manifest, and reproducibility
notes. Raw session payloads, external downloads, media, credentials, logs,
databases, caches, and runtime directories are not publication artifacts.
